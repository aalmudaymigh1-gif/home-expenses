# مصاريف البيت

تطبيق ويب لمشتريات البيت: السائق وعامل النظافة يشترون بالبطاقة اللي معهم (مقاضي، بنزين، صيانة السيارات، أغراض البيت)، ويرسلون صورة الفاتورة. المشرفين يعتمدون ويصرفون الرواتب.

الملف `index.html` هو التطبيق كامل، وينشر على GitHub Pages. القاعدة على Supabase، وملفات SQL والاختبارات في الريبو الخاص `home-expenses-dev`.

## الصفحات
| الصفحة | الرابط |
|---|---|
| المشرف (المالية، الفريق، الإعدادات) | رابط دخول `?k=…` يتحول لجلسة في الجوال |
| الموظف («فواتيري» و«راتبي») | رابطه الخاص `?e=…` من «الإعدادات» |

## الأنواع
مقاضي وأكل، وقود ونقل، صيانة، منظفات ومستلزمات، فواتير خدمات، أخرى، وراتب موظف.

## اللي تغيّر عن النموذج المرجعي
- الخادم التجريبي والبيانات الوهمية انشالت، والاتصال صار بـ Supabase.
- انشالت العهدة والمشاريع والميزانية والحافز والتقييم.
- الدفع: «البطاقة» أو «من حسابه الخاص» (وزر «سدّدته»).
- «المشاريع» صارت «الأنواع» في المالية.
- انضافت صفحة «الإعدادات»: الموظفين (الراتب، يوم الصرف، أول شهر راتب، اللغة، الرابط، الإيقاف)، والمشرفين للمطوّر.
- انضاف الدخول برابط يتحول لجلسة، والأدوار (مشرف كامل، مطوّر للمشاهدة)، و«اعتمدها فلان» على الفاتورة.

## المرحلة الثانية
إشعارات الجوال، وترجمة اللي يكتبه المشرف للموظف.
